# Big Data Applications - Amazon Case Study Analysis

This repository contains the code and analysis for my Big Data Applications summative assignment (Task 1 Amazon Case Study).

Files

- `Jane_Wambaire_Chege__ONL4092502A01_Summative_Task_1_amazon_BIG_DATA_APPLICATIONSWambaire2.ipynb`: Jupyter notebook with the full data cleaning, analysis, and visualization code.

## Key Analysis Areas

1. Time-Based Analysis: Order volume patterns and delivery time distributions
2. Geographic Analysis: Delivery distances and area type impact
3. Factor Analysis: Traffic and weather conditions
4. Agent Performance: Age and rating correlations with delivery time
5. Operational Factors: Vehicle type and product category analysis

## Requirements

- Python 3.x
- pandas
- numpy
- matplotlib
- seaborn
- scipy
